A small clock with a ticking hand marks an active heartbeat on web and desktop. It sits at the end of the agent tab title and uses the idle workspace dot’s position in the sidebar. A heartbeat stays visible between scheduled turns, including while its agent is idle. An agent is also marked if a child, grandchild, or deeper descendant on the same host has an active heartbeat.

Create or cancel heartbeats using Paseo as usual. Indicators refresh automatically and clear after the last matching heartbeat ends. The plugin reads host state and leaves the standard activity spinner and agent execution unchanged.

Only its long hand ticks, once a second. When reduced motion is enabled, both hands stay still.
