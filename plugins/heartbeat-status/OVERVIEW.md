Shows an agent’s active Paseo heartbeats beside its tab title and the workspace sidebar status on web or desktop. A heartbeat stays visible between scheduled turns, including while its agent is idle. An agent is also marked if a child, grandchild, or deeper descendant on the same host has an active heartbeat.

Create or cancel heartbeats using Paseo as usual. Indicators refresh automatically and clear after the last matching heartbeat ends. The plugin reads host state and leaves the standard activity spinner and agent execution unchanged.
