Downloads the file you are previewing in Paseo to your computer with the save shortcut: Cmd+S on macOS, Ctrl+S on Windows and Linux. It works for any file Paseo can preview, including files outside the workspace such as output an agent wrote to `/tmp`, which Paseo's file tree cannot download.

Press the shortcut while a file preview tab is focused. The shortcut follows the focused file in the current window, including when two windows show different files from the same workspace. Other tabs keep their usual shortcuts, including saving edits in a file editor. The shortcut defaults to on and can be turned off for the host under **Settings → Plugins → Download file → Downloads**. The same action is in the Command Center (Ctrl+K or Cmd+K) as "Download current file".

"Open downloads" in the Command Center opens a list of the files downloaded since the page loaded, with their progress and any error. Each entry can be downloaded again, have its path copied, or be removed. The list lives in memory and starts empty after a reload.

Paseo's plugin API does not expose the currently focused tab. The plugin checks the visible file pane in the current window and reads its host, workspace, focus and path from the rendered Paseo component. If a future host changes this structure or several file panes report focus, the shortcut leaves the save action to the browser. To show the shortcut's download and error toasts, the plugin adds an item to the sidebar footer that renders nothing; hiding "Download notices" in Paseo's sidebar settings silences the shortcut's toasts but not the downloads.

Files reach the browser in 4 MiB pieces over the existing Paseo connection, so downloads work through relays and reverse proxies. Browsers with a writable file picker can stream up to 1 GiB to disk. The in-memory download option supports files up to 64 MiB. If another program replaces or edits a file during transfer, the download stops and you can retry from the history. The daemon reads files with its own user's permissions. The plugin works in the desktop app and in the browser.
